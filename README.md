## Running the Notebooks

Most Python-based notebooks can be explored using Jupyter Notebook, JupyterLab, or a compatible cloud notebook environment(like colab).

**To work with the repository locally:**

1. Clone the repository:

`git clone https://github.com/nicole-kutswa/DataraFlow-notebooks.git`

2. Navigate into the project directory:

`cd DataraFlow-notebooks`

3. Create and activate a Python environment, then install the libraries required by the notebook you want to run.

4. Launch Jupyter.

5. Open a notebook and execute its cells in order.

> Note: Some SQL exercises depend on the DataraFlow database and supporting Python modules or connection settings. Running those exercises independently may require access to the relevant database and configuration.
